# ベビー接客えいご（Webアプリ）

ベビーカー・ベビー用品の売り場で、海外のお客さまの接客に使う英語を覚えるためのWebアプリ。
「ハングルの卵」の個別登録機能（自作単語＋お気に入り・検索・覚えたチェック・フラッシュカード・バックアップ）を取り出し、最初から入っている接客フレーズ集と組み合わせたもの。

## ファイル

| ファイル | 中身 |
|---|---|
| `index.html` | アプリ本体（HTML・CSS・JSを1枚にまとめている） |
| `phrases-data.js` | 最初から入っている単語・フレーズ（ベビーカー47語／赤ちゃん・ベビー用品23語／お店・お会計24語／接客のひと言20フレーズ） |

## 手元で開く

```
cd BabyShopEnglish
python3 -m http.server 8765
```

ブラウザで http://localhost:8765/ を開く。

## 保存について

- マイ単語帳（自作・お気に入り）と「覚えた」は、そのブラウザの localStorage にだけ保存される。サーバーには何も送らない。
- 別の端末・別のブラウザとは共有されない。機種変更の前は「…」メニューか設定から「バックアップを書き出す」で保存しておく。
- iPhone の Safari では、プライベートブラウズ中は保存されない。

## フレーズを足すとき

`phrases-data.js` の各カテゴリの **末尾に** 足す。途中に挿入したり削除したりすると、お気に入りや「覚えた」が別の項目に付け替わってしまう（idが並び順で決まるため）。

## お手本の音声（AI音声・無料）

収録済みの単語・例文・フレーズ（208件）は、無料の音声合成AI **Kokoro**（Apache-2.0、商用利用可）でこのMacの中で作った m4a を `audio/` に入れて鳴らす。お金はかからない。
音声ファイルが無いもの（自作単語など）は、ブラウザ標準の読み上げで鳴らす。

```
cd tools
npm install                  # 最初の1回だけ（約420MB。tools/node_modules に入る）
node make-audio.mjs --dry    # 作る件数を確認
node make-audio.mjs          # 作成（初回は音声モデル約90MBをダウンロード）
```

- すでにある音声は作り直さない。`phrases-data.js` の英文を書き換えたり項目を足したりしたら、もう一度実行すればその分だけ作る。
- 声は環境変数 `TTS_VOICE`（既定 af_heart＝アメリカ英語の女性）で変えられる。
- `tools/node_modules` は音声を作るときだけ必要。容量が気になれば消してよい（次に作るときに `npm install` し直す）。
- AIで作った音声であることは、アプリの設定画面に表示している。

## 発音チェック

ブラウザの音声認識（iPhone は Safari、パソコン・Android は Chrome）で話した英語を文字にし、お手本との一致度で 0〜100点を出す。80点以上を正解として、正答率を記録する。
音の細かい正確さではなく「英語として聞き取ってもらえたか」の目安。マイクを使うため、公開するときは https で配信する（localhost は可）。

## 単語の追加

日本語を入れると、英語の候補を出す。候補は「収録済みの単語」と「自動翻訳」（Chrome の端末内翻訳が使えればそれ、なければ MyMemory の無料翻訳API）。自動翻訳を使うとき、入力した日本語は翻訳サービスに送られる。

## 使い方の説明（初回に表示）

実際の画面の写真（`tutorial/*.jpg`）の外側に番号を置き、矢印で押すところを指す。初めて開いたときに出て、ホームの「？」と設定からも見られる。

画面を変えたら写真を撮り直す（ローカルサーバーを起動した状態で `tools/make-shots.sh`。Google Chrome と Xcode のコマンドラインツールが必要）。
- 写真と同じ Chrome で指す部品の位置も測り、`tutorial/marks.json` に書き出すので、写真と矢印がずれない。
- どの部品を指すかは `tools/shot.html` の `marks`、矢印の向き（番号を左右どちらに置くか）は `index.html` の `TUTORIAL` の `points`。

## アイコン

元の絵は `icons/icon.svg`。`tools/make-icons.sh` でホーム画面用（180px）・Android用（192/512px）・タブ用（32px）のPNGを作る。
