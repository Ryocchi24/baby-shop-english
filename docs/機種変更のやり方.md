# ベビー接客えいご　機種変更のやり方

マイ単語帳（自分で追加した単語・♡を付けた単語）、「覚えた」、発音チェックの記録は、スマホの中（Safari）にだけ保存されています。
機種変更の前に、古いスマホで「書き出す」をしておきましょう。

## ① 古いスマホでやること（機種変更の前に）

1. アプリを開き、右上の設定ボタン（つまみのマーク）を押す
2. 「機種変更・バックアップ」の **「① 古いスマホで：書き出す」** を押す
3. **「LINE・メールなどで送る」** を押し、LINE の **Keep メモ**（または自分あてのメール）に送る
   - うまく送れないときは「文字をコピーする」を押して、Keep メモやメモアプリに貼り付けて送る

## ② 新しいスマホでやること

1. **Safari** で https://ryocchi24.github.io/baby-shop-english/ を開く
   - LINE や Chrome から開くと、発音チェックが使えません。必ず Safari で開いてください
2. LINE の Keep メモを開き、送ったバックアップの吹き出しを長押し →「**コピー**」
3. アプリに戻り、設定 → **「② 新しいスマホで：復元する」**
4. **「コピーした文字を貼り付ける」** → **「復元する」**
5. 「復元しました」と出たら完了。マイ単語帳を開いて、単語がそろっているか確認する

## うまくいかないとき

- 「読み込めませんでした」と出たら、バックアップの文字が最初から最後まで全部コピーできていない可能性があります。もう一度コピーし直してください（`{` で始まり `}` で終わる文字です）。
- 新しいスマホでホーム画面に追加し直すときは、Safari の共有ボタン →「ホーム画面に追加」。
